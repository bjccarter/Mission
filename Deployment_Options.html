Deployment Options

How to publish the Christianity Growth Report

Author: Ben Carter

Recommended • Free

1. Netlify (Easiest)

Best choice if you want the report online in under 2 minutes.

  • Go to app.netlify.com
  • Sign up or log in (free)
  • Drag and drop the ZIP file onto the dashboard
  • Your site is live instantly
  • Add your custom domain in Site settings → Domain management
Why choose this: Fastest method. No technical setup required. Free SSL and custom domain included.
Free

2. Azure Static Web Apps

Good if you already use Microsoft Azure or want everything in one ecosystem.

  • Create a free Azure account
  • Create a new Static Web App resource
  • Connect a GitHub repository or deploy manually
  • Add your custom domain in the Azure portal
  • SSL is automatic
Why choose this: Free tier is generous. Strong if you already have an Azure account.
Paid

3. GoDaddy Web Hosting

Works if you want to keep everything with GoDaddy (you already have a domain there).

  • Buy a Web Hosting plan (Economy is enough)
  • Intro price ≈ $5.99/month (3-year term)
  • Upload files to the public_html folder via File Manager or FTP
  • Point your domain to the hosting
Note: More expensive than the free options above for a simple static site.
Free

4. Other Free Options

  • GitHub Pages – Free, reliable, good if you use GitHub
  • Cloudflare Pages – Free and very fast
  • Vercel – Free and excellent for static sites

Files You Need

Download the ZIP package. It contains:

  • index.html – the full report
  • favicon.png – site icon
  • robots.txt – basic search engine file

Once you have the ZIP, you can deploy it using any of the options above.
